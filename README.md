# cloud-notes

Personal study notes and small lab scripts on cloud, infrastructure as code and CI/CD.

These are learning materials, not production code. Everything here is generic and contains no real environments, accounts or credentials.

## Contents

- `aws/`: small AWS lab scripts and notes (bootstrap scripts, EFS tips, links)
- `terraform/`: references and links for Terraform and OCI
- `ci-cd/`: CI/CD pipeline tutorials
