# CI/CD notes

## AWS CodePipeline course material
Course files for *Building CI/CD Pipeline Using AWS CodePipeline* (CodeRed by EC-Council, 2022, MIT License) are kept in an archived repository:

- [Joao-Paulino/CI-CD](https://github.com/Joao-Paulino/CI-CD)

It covers CodeBuild buildspec examples, CodeDeploy CloudFormation templates and ECS deployment files. The material dates from 2022, so check AMIs, runtimes and versions before reusing anything.
